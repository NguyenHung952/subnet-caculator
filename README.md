# Subnet Calculator

Ứng dụng web hỗ trợ **tính toán subnet IPv4**, phục vụ học tập và thực hành mạng máy tính.

## Cấu trúc

```text
subnet-caculator/
├── index.html
├── script.js
├── styles.css
└── README.md
```

## Thành phần

- `index.html`: giao diện nhập thông tin mạng.
- `script.js`: logic tính subnet.
- `styles.css`: định dạng giao diện.

## Mục đích

Giúp tính nhanh các thông tin cơ bản như subnet mask, network và các thông số liên quan từ địa chỉ IPv4.

> Mã nguồn hiện có được giữ nguyên; chỉ cập nhật README.
