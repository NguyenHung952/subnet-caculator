# 🌐 Subnet Calculator

> Công cụ web tính toán **subnet IPv4** nhanh, trực quan và phù hợp cho học tập mạng máy tính.

## ✨ Có gì trong dự án?

- Nhập địa chỉ IPv4 và thông tin subnet.
- Tính các thông số mạng theo logic được triển khai trong JavaScript.
- Hiển thị kết quả trực tiếp trên trình duyệt.
- Giao diện nhẹ, không yêu cầu backend.

## 🧱 Cấu trúc

```text
subnet-caculator/
├── index.html      # Giao diện
├── script.js       # Logic tính subnet
├── styles.css      # Giao diện & responsive
└── README.md
```

## 🚀 Chạy

Mở `index.html` bằng trình duyệt hiện đại. Có thể dùng static server nếu muốn chạy theo môi trường web chuẩn.

## 🛠️ Công nghệ

`HTML5` · `CSS3` · `JavaScript`

## 🎓 Mục đích

Dự án phục vụ học tập và thực hành các khái niệm **IPv4, subnet mask, network address và subnetting**.
